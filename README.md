# كورة سيتي — Kora City

موقع عربي (RTL) مبني من الصفر بـ **HTML + CSS + Vanilla JS فقط** — بدون فريمووركات، بدون باك-إند، جاهز للنشر على Vercel.

## ما هو الموقع؟

دليل معلوماتي لمتابعة كرة القدم: مواعيد مباريات اليوم، القنوات الناقلة الرسمية، أسماء المعلقين، النتائج، أدلة البطولات، والأخبار — بتصميم أصلي داكن مستوحى من تجربة مواقع المباريات (بدون نسخ أي كود أو محتوى أو علامة تجارية).

> **تنبيه مهم:** الموقع معلوماتي فقط — لا يبث المباريات ولا يستضيف أي محتوى محمي بحقوق النشر.

## ⚠️ قبل النشر — تحقق من هذه النقاط

### 1. الدومين
الموقع مضبوط الآن على دومينك الحقيقي `https://koooracity.vercel.app` في:
- وسوم `canonical` و Open Graph في كل صفحة
- بيانات JSON-LD المنظمة
- `sitemap.xml` و `robots.txt`

إذا ربطت دومين مخصص لاحقاً (مثل `koracity.com`)، ابحث عن `koooracity.vercel.app` في كل الملفات واستبدله بالدومين الجديد ثم أعد النشر.

**ملاحظة:** البريد في نموذج الاتصال ما زال `info@koracity.com` (في `assets/js/main.js`) — حدّثه إلى بريدك الحقيقي.

### 2. تحديث جدول المباريات يومياً
جدول `matches.html` (والواجهة الرئيسية) يحتوي مباريات **الجمعة 9 أكتوبر 2026** — بيانات حقيقية جُمعت يوم البناء. المباريات تتغير يومياً، لذا حدّث البطاقات يدوياً كل صباح (الهيكل واضح: انسخ بطاقة `<article class="match-card">` وعدّل الفرق/الوقت/القناة/المعلق)، أو اربط لاحقاً بـ API رياضي.

## النشر على Vercel (بدون Build)

1. ارفع مجلد المشروع إلى مستودع Git (GitHub/GitLab/Bitbucket).
2. في [vercel.com](https://vercel.com) اختر **Add New → Project** ثم **Import** المستودع.
3. إعدادات المشروع:
   - **Framework Preset:** Other
   - **Build Command:** (اتركه فارغاً)
   - **Output Directory:** (اتركه فارغاً — جذر المشروع)
   - **Install Command:** (اتركه فارغاً)
4. اضغط **Deploy**.
5. ملف `vercel.json` مفعّل `cleanUrls` — الروابط مثل `/matches` و`/news` تعمل مباشرة وتدعم التحديث (refresh).
6. لربط دومين مخصص لاحقاً: **Project → Settings → Domains → Add**.

## ملاحظات تقنية

- **الخطوط:** Cairo من Google Fonts مع `display=swap`.
- **نموذج الاتصال:** يعمل عبر `mailto:` (يفتح بريد الزائر) — لا يوجد باك-إند. لاستقبال الرسائل تلقائياً اربط النموذج بخدمة مثل Formspree.
- **SEO:** كل صفحة لها عنوان ووصف وcanonical فريدة، Open Graph، وبيانات JSON-LD (WebSite، Organization، WebPage، BreadcrumbList، SportsEvent، NewsArticle، FAQPage).
- **الأداء:** لا توجد مكتبات خارجية عدا خط Google؛ CSS ملف واحد (~21KB)، وJS ملف واحد (~5.5KB) بتأجيل التحميل.
- **الوصولية:** روابط تخطٍّ، مؤشرات تركيز مرئية، تباين ألوان، دعم `prefers-reduced-motion`، وقائمة جوال بلوحة المفاتيح.
